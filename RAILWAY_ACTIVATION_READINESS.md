## 4. Secret Sharing Architecture: App to Runtime

```
[Vercel Dashboard Environment]
   ├── WORKSPACE_SECRET = "high-entropy-random-32char-secret"
   ├── RAILWAY_API_KEY  = "railway-api-token"
   └── RAILWAY_PROJECT_ID = "railway-project-id"
              │
              ├── [1. Workspace Provisioning via RailwayAdapter]
              │      setServiceVariables injects WORKSPACE_SECRET into container environment.
              │
              ▼
   [Railway Container: ajmeer146/workspace-runtime]
      server.js reads process.env.WORKSPACE_SECRET.
      requireWorkspaceAuth checks req.headers['x-workspace-secret'].
              ▲
              │
              └── [2. Preview Reverse Proxy / Task Execution]
                     app/api/workspace-preview/... injects:
                     headers.set("x-workspace-secret", process.env.WORKSPACE_SECRET)
```

**Security Property:** The secret is never exposed to the browser client. The client requests `/api/workspace-preview/[workspaceId]/...` with an HMAC preview token or user session; the Next.js server verifies ownership, strips user session cookies, and attaches `x-workspace-secret` when proxying to Railway.

## 5. Cost Model & Billing Safety Analysis

### Verified Railway Pricing
- **Platform Fee:** $5/month (Hobby) or $20/month (Pro).
- **RAM Execution:** $0.000231 / GB-hour (~$0.011 / day for a 2GB container).
- **CPU Execution:** $0.000463 / vCPU-hour (~$0.0055 / day for 0.5 vCPU).
- **Persistent Volume:** $0.25 / GB-month ($0.25/month for a 1GB workspace disk).

### Cost-Leak Protection with Cleanup Reaper
- **Without Cleanup Reaper (Uncontrolled):** 10 testing workspaces left running for 30 days = **~$37.50 / month**.
- **With Implemented Reaper (`reapExpiredWorkspaces`):**
  - Workspaces auto-expire after 60 minutes of inactivity.
  - The reaper invokes `adapter.delete(ws.id)` before removing DB records.
  - 10 testing workspaces running for 1 hour each = **less than $0.02 total**.
  - Deletion failures retain DB records so the reaper retries on the next cycle, preventing untracked ghost services.

### Option A: Vercel Pro Account

```json

      "path": "/api/workspaces/cleanup",
```

Vercel Hobby enforces a limit of **once per day** on native crons (`0 0 * * *`). To maintain hourly cleanup without upgrading to Vercel Pro:
- Configure a free external scheduler (e.g., GitHub Actions scheduled workflow, cron-job.org, or Upstash QStash) to send `POST https://www.workswithachu.me/api/workspaces/cleanup` with header `x-cron-secret: <CRON_SECRET>` once per hour.
