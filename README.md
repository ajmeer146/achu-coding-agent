# achu-coding-agent

A simple coding agent tool for automating software engineering tasks.

## Project Description

This project provides an autonomous general-purpose software engineering agent that can:
- Understand user goals and break them into ordered steps
- Inspect existing source code before editing
- Make minimal necessary code changes
- Preserve existing architecture and patterns
- Run verification commands to validate changes
- Handle multi-file coordination and dependencies

## Features

- Code reading and search capabilities
- Edit and file creation tools
- Verification and testing support
- Browser-based live preview verification
- Project structure analysis

## Getting Started

1. Install dependencies: `npm install`
2. Build the project: `npm run build`
3. Start the development server: `npm run dev`
4. Use the agent CLI: `achu-agent <command>`

## Available Scripts

- `test`: Run tests
- `build`: Build TypeScript project
- `dev`: Start development server with tsx
- `start`: Start production server
- `workspace`: Start workspace server
