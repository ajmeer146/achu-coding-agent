## 1. RELEASE OVERVIEW

Achu Coding Agent **v1.1.0** has been officially built, validated, committed, tagged, deployed, and verified live in production across both repositories, Trigger.dev cloud infrastructure, Vercel web platform hosting, and the Windows Local Agent installer delivery pipeline.

### Highlights of v1.1.0 Release:
- **Autonomous 2D Game & 3D Interactive WebGL Scaffolding:** Integrated `scaffold2DGameProject` (Phaser/HTML5 Canvas arcade game with 60 FPS loop, Web Audio API sound synthesis, particles, touch controls, and high-score tracking) and `scaffold3DExperienceProject` (Three.js WebGL interactive 3D scene with dynamic lighting, OrbitControls, and HUD panel).
- **Intra-turn Tool Call Deduplication:** Implemented deterministic deduplication in `src/agent.ts`, eliminating duplicate file reads and redundant writes within a turn while strictly preserving the LLM tool-calling schema contract.
- **Model Routing & Zero-Stall Fast Failover:** Configured canonical `PRIMARY_MODEL = "minimaxai/minimax-m3.1-flash"` on NVIDIA NIM with fast timeout failover to `FALLBACK_MODEL = "nvidia/nemotron-3.5-lightning-30b-a3b"` (<1s response latency) and active turn stickiness.
- **Deployment Reconciliation Engine:** Upgraded Vercel and GitHub deployment pipeline in `works-with-achu-v2` with watchdog recovery, stage-by-stage telemetry, auto-reconciliation, and user retry controls.
- **Windows Local Agent v1.1.0 Installer:** Built with Inno Setup, bundled with Node.js runtime, verified Authenticode structure, and synchronized byte-for-byte with the production download endpoint.
